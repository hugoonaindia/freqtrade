# macOS application packaging

Goal: deliver Desktop/Apps funcionales/Freqtrade Bolsa.app, native Apple Silicon window with bundled Python backend and backtester.

Architecture: native Cocoa/WKWebView launcher, PyInstaller arm64 onedir backend in bundle Resources, bundled HTML/JS and TLS certificate roots. Writable runtime is ~/Library/Application Support/Freqtrade Bolsa; credentials never embedded in distributable app. Desktop settings preserve existing Paper SMA/AAPL/MSFT/500 configuration. Single backend runtime lock and lightweight health endpoint prevent duplicate instances. Closing native window stops owned backend; attaching to another existing backend never stops that process.

1. Regression tests for runtime paths, launch settings and service identity.
2. Implement runtime path helper and desktop backend entry point, leaving repository CLI defaults compatible.
3. Build native launcher with readiness/error handling, normal Quit menu and JSON report downloads. Bundle arm64 backend, assets and CA roots; ad-hoc sign app.
4. Validate bundled backend on a separate manual port without affecting existing Paper process. Run isolated full suite, verify binary architecture/signature and real account/data/backtest through bundled binary.
5. Securely copy credentials, submission guard and reports to writable runtime; migrate existing process to packaged app preserving active automation and avoid overlapping traders. Validate native window and active Paper state after launch.

No system Python required after packaging. No Apple notarization identity is available; local ad-hoc signing targets this user's Mac.
