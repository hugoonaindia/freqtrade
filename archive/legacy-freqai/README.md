# Historical FreqAI TensorFlow models

Preserved from the historical JOSS and CNN branches during branch consolidation. These models target retired FreqAI APIs and TensorFlow 2.11. They are archived outside the active model discovery directory and require porting before use. Current FreqAI APIs and dependencies take precedence in merge conflicts. The historical spice-rack integration also requires porting; its documentation and configuration are preserved, but it is not enabled in the current runtime.
